CARA MENJALANKAN
1. Pastikan Python sudah terpasang.
2. Simpan semua file dalam satu folder dengan struktur yang sama.
3. Jalankan: python menu_anggota1.py

FORMAT TANGGAL
Gunakan YYYY-MM-DD, contoh 2026-11-23.

SKEMA DATA LAHAN
id | nama | lokasi | luas | tanaman | tanggal_tanam

SKEMA DATA PANEN
id | id_lahan | tanggal_panen | jumlah_kg | harga_per_kg | total_nilai

CATATAN UNTUK KELOMPOK
Samakan nama fungsi, parameter, dan kolom data dengan anggota lain sebelum integrasi.
File ini merupakan implementasi awal yang mandiri. Fungsi menu dapat dipindahkan ke
modul gabungan kelompok setelah semua fungsi selesai.
